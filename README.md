# SpeesRep

Offline-first Dutch flashcards (PWA) for a French-speaking learner. Content is edited in a Google
Sheet and served by an Apps Script API; reviews are scheduled with FSRS and synced when online.

- App: https://speesrep.github.io/NT2/ · DEV: https://speesrep.github.io/NT2/dev/
- Developer guide: [CLAUDE.md](CLAUDE.md) · Sheet schema: [docs/SHEET.md](docs/SHEET.md) · Releasing: [docs/RELEASE.md](docs/RELEASE.md)

```bash
npm install
npm run dev
```
